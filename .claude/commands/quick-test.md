# 簡易テスト実行

変更内容に応じて適切なテストを実行します。

## テスト種類

### 1. Javaコード（バックエンド）

#### コンパイルチェック
```bash
./mvnw clean compile
```

#### ユニットテスト実行
```bash
./mvnw test
```

#### 特定のテストクラスのみ実行
```bash
./mvnw test -Dtest=AtBatResultServiceTest
```

#### アプリケーション起動確認
```bash
./mvnw spring-boot:run
```

### 2. Vueコード（フロントエンド）

#### 開発サーバー起動確認
```bash
cd vue-project
npm run dev
```

#### ビルド確認
```bash
cd vue-project
npm run build
```

#### Lint実行
```bash
cd vue-project
npm run lint
```

### 3. 統合確認

#### フルビルド
```bash
# フロントエンドビルド
cd vue-project
npm run build
cd ..

# バックエンドビルド
./mvnw clean package -DskipTests
```

## 実行フロー

1. **変更内容の分析**: どのファイルが変更されたかを確認
2. **適切なテストの選択**: 変更に応じて必要なテストを選択
3. **テスト実行**: 選択したテストを実行
4. **結果報告**:
   - ✅ 成功: 何が確認できたか
   - ❌ 失敗: エラー内容と対処方法

## 判定基準

### Javaコード変更時
- Entity/Repository変更 → コンパイル + 関連テスト
- Service変更 → コンパイル + Serviceテスト
- Controller変更 → コンパイル + 統合テスト（可能なら）
- Scraper変更 → コンパイル確認

### Vueコード変更時
- コンポーネント変更 → Lint + 開発サーバー起動確認
- スタイル変更 → 開発サーバー起動確認
- ビルド設定変更 → ビルド確認

### 両方変更時
- フルビルド + 動作確認

## 出力形式

```markdown
## テスト実行結果

### 実行したテスト
- テスト名1
- テスト名2

### 結果
✅ 成功 / ❌ 失敗

### 詳細
- 確認できた内容
- エラー内容（失敗時）
- 対処方法（失敗時）

### 次のステップ
- 推奨される次の行動
```

## 使用方法

### 自動判定でテスト実行
```
/quick-test
```

### 特定のテストを指定
```
/quick-test java
/quick-test vue
/quick-test full
```

## 注意事項

- テストは実際に実行し、結果を報告
- エラーが発生した場合は、エラー内容を詳細に報告
- 開発サーバーをバックグラウンドで起動する場合は、適切に停止
- テスト実行前に必要な依存関係がインストールされているか確認
- より本格的なテスト（テストケース設計・境界値・エッジケース含む）が必要な場合は `/team` のQAエンジニアを活用
